## 3. 运行环境与约束

依据 Quicker 官方文档 [1][2]：

- 【自定义窗口】根据 XAML 创建 WPF 窗口，支持简单的数据绑定和事件。
- XAML 必须去掉 `x:Class`，不能指定事件处理方法，需要注册 `xmlns:qk="https://getquicker.net"`。
- 窗口数据保存在词典中；窗口关闭时，【数据映射】中关联的动作变量会被写回。
- 【辅助C#代码】提供 `OnWindowCreated`、`OnWindowLoaded`、`OnButtonClicked` 回调。
- Quicker 自定义窗口的辅助代码按 C# 5.0 语法编译，因此本项目未使用字符串插值、`?.`、`nameof`、表达式体成员等较新语法。
- 项目只使用 .NET Framework 与 WPF 标准库；`System.Windows.Forms` 仅用于 `FolderBrowserDialog` 和 `MessageBox`，与官方文档示例一致。

## 4. 架构设计

### 4.1 总体结构

```text
Quicker 动作变量
  ├─ 输入文件路径（列表）
  ├─ 最早起始年份（整数）
  └─ 批量重命名器预设（词典）
          │
          ▼
【自定义窗口】数据映射 → 窗口 dataContext
          │
          ▼
OnWindowLoaded
  ├─ 读取配置、初始化控件与胶囊编辑器
  ├─ 收集输入路径（判断文件/文件夹、去重、规范化）
  ├─ 启动扫描线程：FileInfo + EXIF
  └─ 启动哈希线程（仅模板含【校验码】时）
          │
          ▼
ObservableCollection<Dictionary<string,object>> → DataGrid 两列预览
          │
          ├─ 配置变化 → RecomputeAll → 目标路径实时刷新
          ├─ 行悬浮 → Details 文本（全部日期、大小、校验码、状态）
          └─ 生成输出 → 两个列表 + 预设词典
```

### 4.2 模块职责

| 模块 | 职责 | 依赖 |
|---|---|---|
| `RenamerCore.cs` | 文件名日期提取、算法位数、校验码格式、CRC32/BLAKE3/MD5/SHA-256、模板解析、路径规范化与校验、配置与预设转换 | 仅 BCL |
| `CustomWindow.Aux.cs` | 控件查找与事件、配置同步、文件扫描、EXIF 读取、哈希调度、DataGrid 行数据、胶囊编辑器、预设载入/保存、输出 | 核心逻辑、WPF、WinForms 对话框 |
| `CustomWindow.xaml` | 窗口布局、样式、两列表格、状态栏、胶囊按钮 | WPF |

依赖方向为 `XAML/UI → Core`，核心逻辑不引用 WPF，便于在 Linux/Mono 下编译测试。

### 4.3 线程模型

| 线程/机制 | 工作内容 | 与 UI 的交互 |
|---|---|---|
| UI 线程 | 控件事件、配置读取、目标路径计算、DataGrid 刷新、输出 | 直接操作 |
| 扫描线程 | `FileInfo`、EXIF 解码 | 每 50 个文件通过 `Dispatcher.BeginInvoke` 批量加入 UI |
| 哈希线程 | 顺序计算文件校验码 | 每 5 个文件投递进度；完成后触发重算 |
| `DispatcherTimer` | 文本配置 250 ms 防抖 | 防抖后统一刷新 |

并发控制：

- 扫描与哈希均使用递增的 generation 编号；窗口关闭、重新扫描或切换算法后，旧线程的结果会被丢弃。
- 哈希缓存使用 `lock` 保护，键为 `路径|算法`。
- UI 控件、`_files`、`_rows` 只在 UI 线程读写。
- 静态状态按单窗口使用设计；`Window_Closed` 会校验窗口引用，避免旧窗口清理新窗口状态。

### 4.4 状态与生命周期

- `OnWindowCreated`：初始化输出列表为空，避免取消后残留上一次结果。
- `OnWindowLoaded`：重置静态状态、建立默认配置、绑定事件、开始扫描。
- 窗口关闭：递增 generation、停止防抖计时器、清理控件引用与缓存。
- 默认不自动载入预设；用户点击【载入预设】后才应用，符合需求中“载入”按钮的显式交互。
- 实时刷新关闭时，配置变更只更新配置与日期数据并置 `_previewDirty`；`RecomputeAll` 与哈希进度刷新会被该标记阻止，直到【预览】/【生成输出】执行完整刷新。
- 扫描结束、预设载入、开启实时刷新、手动预览会清除 `_previewDirty` 并完整重算。

## 5. 功能实现说明

### 5.1 输入路径与文件筛选

1. 兼容 `List<string>`、`List<object>` 及单个字符串。
2. 使用 `Path.GetFullPath` 规范化；相对路径按 Quicker 进程当前目录解析。
3. 先判断目录：`Directory.Exists` 为真则跳过并计数。
4. 再判断文件：`File.Exists` 为假则跳过并计数。
5. 使用 `HashSet<string>(OrdinalIgnoreCase)` 去重，保持首次出现顺序。
6. 文件夹、无效路径不进入表格；状态栏显示跳过数量。
7. 过滤器（扩展名列表）：
   - 扩展名列表支持逗号、分号、空格、换行、`|` 分隔，支持 `*` 通配全部；空列表表示不过滤。
   - 决策模式 `skip`：命中列表的文件跳过；`execute`：仅命中列表的文件执行，其他跳过。
   - 被过滤跳过的文件不计算目标路径、不计算哈希、不进入输出列表；表格中以灰色行显示“过滤跳过”。
8. 扩展名预设：
   - 独立词典变量【扩展名预设】；保存命名列表；载入时选择覆盖或追加。
   - 保存后尝试通过 `winContext.Context.SetVarValue` 实时写回动作变量。

### 5.2 日期属性

#### 文件名中的日期

- 格式1：`yyyy-mm-dd`，正则 `(?<!\d)(\d{4})-(\d{2})-(\d{2})`。
- 格式2：`yyyymmdd`，正则 `(?<!\d)(\d{8})`。
- 先验条件：匹配位置为字符串起始或前一个字符不是数字；不校验后边界，日期后允许是时间、文件名或连接符。
- 年份范围：`最早起始年份` 至当前年份，含边界；月份 1–12，日期按公历校验。
- 优先尝试格式1；格式1没有有效日期时再尝试格式2；同一格式内取第一个有效日期。
- 只匹配文件名（不含扩展名）。

#### EXIF 拍摄日期

- 通过 WPF `BitmapDecoder` + `BitmapMetadata` 读取，避免额外依赖。
- 查询顺序：`DateTimeOriginal (36867)` → `DateTimeDigitized (36868)` → `DateTime (306)`。
- 仅对常见图片扩展名尝试：`.jpg/.jpeg/.tif/.tiff/.png/.bmp/.gif/.heic/.heif/.webp`；实际能否读取取决于系统 WIC 编解码器。
- 支持 `yyyy:MM:dd HH:mm:ss`、`yyyy-MM-dd HH:mm:ss` 等格式，并做宽松解析回退。

#### 生效日期

- 修改日期、创建日期来自 `FileInfo.LastWriteTime` / `CreationTime`。
- 【配置3.1】选中的日期来源优先。
- 递补1~5在同一行；每项可选四类日期来源、空值、自定义、跳过；递补5默认空值。
- 递补按顺序处理：日期来源可用则采用；空值=三个日期胶囊为空并停止；自定义=使用统一自定义值并停止；跳过=该文件不处理、不输出。
- 空值/空字符串下【日期yyyy】【日期mm】【日期dd】都为空。
- 行悬浮信息中显示“生效日期（来源：…）”；日期缺失时显示替换值/跳过状态。

### 5.3 校验码

| 算法 | 最高16进制位数 | 实现 |
|---|---:|---|
| CRC32 | 8 | 多项式 `0xEDB88320`，流式计算 |
| BLAKE3 | 64 | 托管流式实现，默认32字节输出 |
| MD5 | 32 | `System.Security.Cryptography.MD5` |
| SHA-256 | 64 | `System.Security.Cryptography.SHA256` |

格式规则：

```text
前缀 + 算法标识 + "-" + 截断后的16进制校验码 + 后缀

默认前缀 "["、后缀 "]"：
位数等于算法最高位数： [CRC32-7f7f7f7f]
位数小于最高位数：     [CRC32_4-7f7f]
自定义前缀/后缀：      CHK:CRC32_4-7f7f:END
```

- 位数范围 1 至算法最高位数；切换算法时，如果原位数等于旧算法最高位数，则自动改为新算法最高位数，否则按新算法上限截断。
- 截取规则：取完整16进制串的前 N 位（高位）。
- 前缀、后缀默认分别为 `[` 和 `]`，直接位于“算法标识-校验码”两侧，不再额外套固定方括号。
- 模板不含【校验码】时不计算哈希；含有时在后台顺序计算，完成后刷新预览。
- 哈希失败（权限、占用、算法不可用等）会将行标记为错误。

### 5.4 模板与胶囊编辑器

支持的七个胶囊：

| 胶囊 | 值 |
|---|---|
| 【日期yyyy】 | 生效日期的四位年份 |
| 【日期mm】 | 两位月份 |
| 【日期dd】 | 两位日期 |
| 【根路径】 | 当前文件所在目录或用户选择的固定目录 |
| 【源文件名】 | 不含扩展名的文件名 |
| 【扩展名】 | 不含点的扩展名 |
| 【校验码】 | 按 5.3 生成的校验码文本 |

编辑器实现：

- 使用 `RichTextBox`；胶囊渲染为 `InlineUIContainer` + `Border` 的可视元素。
- 点击胶囊按钮时，将胶囊插入到最近一次记录的光标位置；插入后光标移动到胶囊之后。
- 文本与胶囊统一序列化为带 `【…】` 的模板字符串，用于预览与预设保存。
- 载入预设或恢复默认模板时，重新解析模板并生成胶囊。
- 未知 `【…】` 胶囊会被保留显示，但目标路径计算会报“模板包含未知胶囊”。
- 默认模板为 `【根路径】/【日期yyyy】.【日期mm】/aaa/bbb/【源文件名】-【校验码】.【扩展名】`。

### 5.5 目标路径组合与校验

- 根路径模式：
  - `current`：每个源文件所在目录（默认）。
  - `custom`：用户通过文件夹选择器指定的固定目录。
- 模板未包含【根路径】且渲染结果不是绝对路径时，自动拼接到根路径下。
- 允许模板直接写绝对路径（如 `D:/Out/...`），此时忽略根路径。
- 路径分隔符统一为 Windows 反斜杠；连续分隔符折叠；保留 UNC 的 `\\server\share` 前缀。
- 不解析 `..`：含 `.` 或 `..` 段的路径判为错误。
- 校验项（跨平台并集）：
  - 必须是 `X:\...` 或 `\\server\share\...` 绝对路径。
  - 非法字符并集：`< > : " / \ | ? *`、ASCII 控制字符（NUL 等）；`/` 在规范化阶段转为分隔符。
  - 路径段不能为空、不能是 `.`/`..`、不能以空格或点结尾。
  - Windows 保留设备名（CON/PRN/AUX/NUL/CLOCK$/CONIN$/CONOUT$/COM0–9/LPT0–9）判为错误。
  - 路径段长度不超过 255 字符且 UTF-8 不超过 255 字节。
  - 总路径不超过 259 字符且 UTF-8 不超过 1024 字节（取 Windows/macOS 的严格限制）。
  - 必须包含文件名。
- 冲突处理：
  - 批内目标路径重复（忽略大小写）→ 标记“目标重复”。
  - 目标文件或目录已存在且不等于源路径 → 标记“目标已存在”。
  - 目标等于源路径 → 标记“无变化”，仍视为可输出。
- 错误提示：
  - 顶部 ErrorBanner 汇总异常数量与前 5 类错误，红字显示。
  - 表格异常行使用红底高亮；行悬浮显示完整错误。
- 不检查 POSIX 文件名规范化差异与 Windows 长路径前缀 `\\?\`，见第 9 章。

### 5.6 预设

预设使用 Quicker 词典；单套配置为扁平键值，多套命名预设放在 `presets` 嵌套词典中。单套配置键名与类型如下：

| 键 | 值示例 | 说明 |
|---|---|---|
| `presetVersion` | `0.04` | 单套配置结构版本 |
| `rootMode` | `current` / `custom` | 根路径模式 |
| `rootPath` | `D:\Output` | 固定根路径，模式为 current 时也会保留 |
| `startYear` | `2000` | 最早起始年份（字符串存储） |
| `filterExtensions` | `jpg;png` | 过滤器扩展名列表 |
| `filterMode` | `skip` / `execute` | 匹配时跳过/匹配时执行 |
| `dateSource` | `filename/exif/modified/created` | 主选日期来源 |
| `dateFallbackOrder` | `filename,exif,modified,created,empty` | 递补1~5（日期来源/空值/自定义/跳过） |
| `dateFallbackCustomText` | 空字符串 | 递补选择“自定义”时的统一文本 |
| `realTimePreview` | `true` / `false` | 实时刷新开关 |
| `checksumAlgorithm` | `CRC32/BLAKE3/MD5/SHA-256` | 校验算法 |
| `checksumDigits` | `8` | 16进制位数（字符串存储） |
| `checksumPrefix` | `[` | 校验码前缀，默认 `[` |
| `checksumSuffix` | `]` | 校验码后缀，默认 `]` |
| `template` | `【根路径】/...` | 模板原文 |

多预设词典结构：

```text
{
  "presetVersion": "0.04",
  "presets": {
    "预设名A": { ...单套配置... },
    "预设名B": { ...单套配置... }
  }
}
```

- `BuildPresetDictionary` 先规范化配置，再输出单套配置的全部键。
- 词典输出支持多套命名预设；窗口内通过【载入预设】下拉选择、【保存预设】命名保存。
- 旧版扁平单预设没有 `presets` 键时，作为“默认”预设识别。
- 同名判断忽略大小写；覆盖前显示变更项目（旧值→新值）。
- 点击【生成输出】时若预设词典为空，会自动把当前配置保存为“默认”预设输出。
- 保存预设后尝试通过反射调用 `SetVarValue`（`ICustomWindowContext` 自身或 `Context`/`GetRootContext()`）实时更新动作变量【批量重命名器预设】；若版本不暴露该接口，关闭窗口时由数据映射写回。
- 扩展名预设独立存于【扩展名预设】词典：
  - 结构：`{ "presetVersion": "0.04", "presets": { "名称": "jpg;png" } }`。
  - 载入时询问覆盖或追加；追加使用扩展名规范化后合并。
  - 保存后同样尝试实时写回动作变量。
- 预设只通过动作词典输入/输出，不写本地文件。

### 5.7 输出契约

【生成输出】点击后：

1. 立即读取当前 UI 配置并刷新预览（等价于手动预览），避免输出旧配置。
2. 若仍有校验码在计算，提示等待。
3. 若存在异常行但仍有就绪行，弹窗确认后仅输出就绪行。
4. 使用成对列表构造输出，保证两个列表长度一致：
   - `origPaths`：列表【原路径和文件名】。
   - `targetPaths`：列表【目标路径和文件名】。
   - `preset`：词典【批量重命名器预设】，包含已保存的多套命名预设；若尚未保存任何预设，则自动写入当前配置为“默认”。
5. 两个列表第 n 项来自同一源文件，顺序与输入文件顺序一致（去重后），不包含文件夹、无效路径、异常行、计算中行。
6. 点击【取消】或直接关闭窗口：两个输出列表为空；已点击【保存预设】的配置仍会随窗口关闭写回预设。

预览阶段不执行任何文件写入操作。

### 5.8 实时刷新与手动预览

- 【实时刷新】默认开启。
- 开启时：配置变更立即重算目标路径；【预览】按钮禁用。
- 关闭时：
  - 配置变更只更新配置与必要的日期数据，目标路径保持上一次预览结果。
  - 状态栏提示“配置已变更，点击【预览】刷新目标路径”，【生成输出】禁用。
  - 点击【预览】时，读取当前配置并完整刷新预览；刷新完成后恢复【生成输出】。
- 实时刷新关闭时，日期相关配置变更仍会重新计算文件名日期/生效日期并刷新行悬浮信息，但目标路径列保持旧值，直到手动预览。
- 开启实时刷新会立即完整刷新一次，以吸收关闭期间累积的配置变更。

### 5.9 界面布局、预设与悬浮说明

- 配置区为五张纵向卡片：过滤器、根路径、日期、校验码、模板。
- 卡片标题放在左侧竖排区域；说明不占正文，改为悬浮在标题上显示。
- 对应胶囊在同一行右侧：
  - 根路径卡片 → 【根路径】。
  - 日期卡片 → 【日期yyyy】【日期mm】【日期dd】。
  - 校验码卡片 → 【校验码】。
- 模板卡片在下方：左侧模板编辑器，右侧为【源文件名】【扩展名】；所有胶囊在右列纵向排列。
- 日期递补1~5在同一行；每项可选四类日期来源、空值、自定义、跳过；共享一个自定义值输入框。
- 过滤器卡片包含扩展名列表、决策模式、载入/保存扩展名预设按钮。
- 【载入预设】【保存预设】位于窗口顶部；实时刷新与【预览】也在顶部。
- 【载入预设】打开 `Popup` 列表，按名称排序展示所有预设；单击即载入。
- 【保存预设】弹出名称输入对话框；同名（忽略大小写）时比较旧配置与当前配置，展示变更项目并确认覆盖。
- 【载入扩展名预设】使用下拉菜单选择名称，并询问覆盖或追加。
- 多预设存储在 `presets` 嵌套词典；旧版扁平单预设识别为“默认”。
- 所有配置控件、胶囊、预设/预览/输出/取消按钮均通过 `AttachToolTips` 设置悬浮提示，说明含义、输出结果和后果；禁用控件也可显示提示。
- 错误提示条 `ErrorBanner` 位于顶部，汇总异常数量与前5类错误；异常行红底、校验码计算中黄底、过滤/日期跳过灰底。

## 6. UI 与交互设计

### 6.1 布局

| 区域 | 内容 |
|---|---|
| 顶部工具栏 | 标题/提示；实时刷新、预览、载入预设、保存预设 |
| 顶部错误区 | ErrorBanner：红字汇总异常路径；无异常时折叠 |
| 配置区（左） | 过滤器、根路径、日期、校验码、模板五张纵向卡片；每张卡片标题在左列（约78px）竖排，不占顶部纵向空间；说明改为标题悬浮提示；模板编辑器高度72 |
| 胶囊列（右） | 固定250px宽；按卡片行排列【根路径】、三个日期胶囊、【校验码】、【源文件名】、【扩展名】 |
| 中部表格 | 两列：源路径名、目标路径名/文件名；行悬浮显示属性 |
| 底部状态区 | 进度条、状态统计、取消、生成输出 |

### 6.2 视觉与状态

- 窗口背景浅灰 `#F5F6F8`，配置与表格使用白色卡片、`#E3E6EB` 边框、6 px 圆角。
- 主按钮蓝色 `#1570EF`；胶囊按钮浅蓝底、圆角胶囊样式。
- 表格行状态：
  - 正常：白/浅灰交替。
  - 异常：浅红底 `#FFF1F0` + 深红字。
  - 校验码计算中：浅黄底 `#FFFAEB` + 棕色字。
  - 被过滤器或日期递补“跳过”：灰底灰字，不参与目标路径、哈希与输出。
- 行悬浮 ToolTip 显示源文件、目录、大小、四类日期、生效日期与来源、扩展名、校验码、目标路径、状态/错误。
- 状态栏显示总数、跳过文件夹/无效路径数、过滤/日期跳过数、就绪/异常/计算中数量与哈希进度。

### 6.3 交互流程

1. 打开窗口 → 自动读取输入路径与属性，表格逐步填充；先按过滤器扩展名与决策模式标记跳过行。
2. 选择根路径模式；选择“其他文件夹”立即弹出文件夹选择器，取消且无历史路径时回退到“当前文件夹”。
3. 修改起始年份 → 重新计算文件名日期；修改日期来源/递补1~5 → 重新选择生效日期；递补选择空值/自定义/跳过时立即按对应语义处理。
4. 编辑模板或点击右侧胶囊 → 250 ms 防抖；实时刷新开启时立即刷新目标路径，关闭时提示手动预览。
5. 修改校验算法/位数/前后缀 → 更新格式预览；实时刷新开启时按需后台重算哈希。
6. 实时刷新关闭时，配置变更后点击【预览】刷新；【生成输出】在预览过期时禁用。
7. 发现非法路径 → 顶部红字提示，异常行红底高亮；悬浮行可查看完整错误；跳过行不进入错误统计。
8. 点击【载入预设】→ 顶部下方弹出预设列表，单击名称载入；旧版单预设显示为“默认”。
9. 点击【保存预设】→ 输入名称；同名时显示变更项目并确认覆盖；保存后写入多预设词典并尝试实时写回动作变量。
10. 点击【载入扩展名预设】→ 下拉选择名称，询问“覆盖/追加/取消”；点击【保存扩展名预设】→ 命名保存并尝试实时写回【扩展名预设】。
11. 点击【生成输出】输出两个等长、序号配对的列表（排除过滤/日期跳过行）；点击【取消】放弃输出。
12. 悬浮任意配置项、卡片标题、胶囊或主要按钮可查看用途、结果与后果。

胶囊编辑器说明：

- 胶囊是原子内联元素；可整体选中后删除。
- 从外部粘贴富文本时，`Span` 内文字会被序列化保留，但不会自动转换为胶囊。
- 光标离开编辑器后仍保留最近光标位置，用于胶囊按钮插入。

### 7.3 数据映射

```text

startYear:{最早起始年份}
```

本动作只负责预览与输出，不包含实际重命名步骤。后续可使用 Quicker 的文件操作步骤，依次读取两个列表并执行移动/重命名。

## 8. 设计决策与需求映射

需求文档第10章仍有待确认项。当前实现采用以下口径，均可在后续版本调整：

| 需求项 | 当前实现 |
|---|---|
| 文件名日期边界与优先级 | 只校验前边界；格式1优先；同格式取第一个有效日期 |
| 日期来源缺失 | 递补1~5同行；每项可选四类日期、空值、自定义、跳过；默认顺序 filename→exif→modified→created→empty；空值=三胶囊为空并停止，自定义=统一替换并停止，跳过=不处理/不输出 |
| 过滤器 | 扩展名列表 + 决策模式（匹配时跳过/匹配时执行）；命名保存/载入独立【扩展名预设】词典，载入可选覆盖或追加 |
| 校验码前缀/后缀 | 直接包裹“算法[_位数]-校验码”，默认 `[`、`]` |
| 预设存储 | 多套命名预设存于 `presets` 嵌套词典；旧版扁平预设识别为“默认”；同名忽略大小写，覆盖前显示变更 |
| 递补兜底 | 递补5默认为空值；空值下三个日期胶囊都为空；也可设为自定义或跳过 |
| 模板未包含【根路径】 | 视为相对路径，拼接到根路径下 |
| 非法/重名/已存在 | 标记错误；异常行不输出；有异常时弹窗确认；顶部红字汇总 |
| 输出顺序与配对 | 输入顺序（去重后），不占位；成对构造，长度与序号严格一致 |
| 默认模板 | `【根路径】/【日期yyyy】.【日期mm】/aaa/bbb/【源文件名】-【校验码】.【扩展名】` |
| 校验码计算时机 | 模板含【校验码】时后台计算；生成输出前等待完成 |
| 实时刷新 | 默认开启；关闭时手动预览，预览过期时禁用生成输出 |
| “当前文件夹” | 每个源文件所在目录 |
| BLAKE3 输出 | 32字节 / 64位16进制，取前 N 位 |
| 路径分隔符 | 统一反斜杠；折叠重复分隔符；保留 UNC 前缀 |
| 跨平台校验 | 非法字符并集 + 保留名 + 段/总路径长度限制 |

## 9. 限制与已知风险

1. **单窗口静态状态**：界面状态保存在静态字段中，按同一时间只打开一个批量重命名器窗口设计；避免同时打开多个实例。
2. **仅预览**：不执行重命名、移动、复制或删除；目标目录不会自动创建。
3. **C# 5.0**：代码按 Quicker 自定义窗口的 C# 5 环境编写；不要直接引入需要更高语言版本的语法。
4. **EXIF 依赖 WIC**：只对常见图片扩展名尝试；RAW 文件、缺少系统编解码器的 HEIC/HEIF/WebP 可能读不到拍摄日期。
5. **无扩展名文件**：默认模板含 `.【扩展名】`，扩展名为空时会形成结尾点并判为非法路径；可自定义模板去掉该点。
6. **跨平台路径长度**：为兼容 Windows/macOS/Linux/Android，当前限制为路径段≤255字符且≤255 UTF-8字节、总路径≤259字符且≤1024 UTF-8字节；会拒绝部分系统本身可接受的长路径。
7. **哈希耗时**：哈希顺序执行，BLAKE3 为托管实现；大批量/大文件时总耗时较长，但 UI 保持响应。
8. **预设不持久化到文件**：依赖 Quicker 动作词典；支持多套命名预设与独立【扩展名预设】，但嵌套词典的持久化行为需实机验证。
9. **实时变量写入依赖接口**：优先反射调用 `ICustomWindowContext` 自身或 `Context`/`GetRootContext()` 上的 `SetVarValue` 实时写回；若当前 Quicker 版本不暴露上述接口，则退回到窗口关闭时由数据映射写回，此时运行中读取动作变量可能仍是旧值。
10. **过滤器范围**：APP_FileSettle 仓库在本环境不可访问；当前仅实现扩展名列表与跳过/执行决策，尚未实现关键词、正则、大小、日期等筛选规则。
11. **文件在窗口打开期间变化**：属性只在打开时读取，之后不会自动刷新；需要重新打开窗口。
12. **ToolTip 长路径**：超长源路径可能使悬浮提示较宽；可后续改为带换行的自定义 ToolTip。
13. **实时刷新关闭时**：目标路径列会保持旧值，状态栏与禁用生成输出提示预览过期；日期属性仍会按配置更新。
14. **缺失日期与默认模板**：递补选择空值或自定义空字符串时，默认模板可能形成 `.` 目录段并因此报非法路径；可改为自定义非空日期文本、选择跳过或调整模板。
