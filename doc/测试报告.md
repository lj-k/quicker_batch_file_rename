### 2.5 示例1验证

输入路径：`C:\A\B\C\D.TXT`

模板：

```text
【根路径】/【日期yyyy】.【日期mm】/aaa/bbb/【源文件名】-【校验码】.【扩展名】
```

参数：根路径=当前文件夹，日期=2020-06，校验码=`[CRC32_4-7f7f]`。

```text
C:\A\B\C\2020.06\aaa\bbb\D-[CRC32_4-7f7f].TXT
```

与修订后的需求示例一致（路径分隔符按 Windows 规范使用反斜杠）。

### 2.6 预设往返

测试配置包含：

```text
rootMode=custom, rootPath=D:\Out, startYear=2010,
filterExtensions=jpg;png, filterMode=move,
dateSource=exif, dateFallbackOrder=exif,created,custom,empty,skip,
dateFallbackCustomText=兜底日期,
realTimePreview=false, execParallel=5, execVerify=false,
checksumAlgorithm=SHA-256, checksumDigits=16,
checksumPrefix=P, checksumSuffix=S,
template=【根路径】/X-【校验码】.【扩展名】
```

`BuildPresetDictionary` → `ApplyPresetDictionary` 后，全部键值一致；另验证：

- 部分预设只更新存在的键。
- CRC32 位数 99 被规范化为 8；execParallel 99 被规范化为 8。
- 中文“修改日期”“其他文件夹”、`sha256` 别名被正确识别。
- 旧版 `execute` 模式迁移为 `rename`。
- 重命名模式且预设没有模板键时，使用重命名默认模板；显式通用模板保持不覆盖。
- 默认前缀/后缀为 `[`/`]`。
- 默认过滤器为空、默认模式 `skip`、默认并行 2、默认执行后校验开启。
- 默认递补顺序 `filename,exif,modified,created,empty`，默认自定义文本为空。
- 预设版本为 0.05。

### 2.8 日期递补与解析

- 主选存在 → 主选优先。
- 主选缺失、递补1可用 → 按顺序取下一个可用日期。
- 递补选择【空值】→ 返回空日期并停止，三个日期胶囊都为空。
- 递补选择【自定义】→ 返回统一自定义值并停止，三个日期胶囊都替换。
- 递补选择【跳过】→ 标记该文件跳过，不处理、不输出。
- 递补顺序重复项去重并按5槽补齐；`跳过,自定义,空值,文件名,创建` 等中文别名可识别。
- 默认顺序 `filename,exif,modified,created,empty`。
- 旧版 `dateFallback5Text`、旧四槽顺序可迁移。

### 2.10 输出配对

生成输出/方案1执行均使用三个列表（源路径、目标路径、动作），按同一批非跳过行逐项填充，并在写入窗口数据前校验三者长度一致；因此第 n 项严格对应同一源文件。方案2不生成/写入列表变量。

### 2.11 过滤器与动作匹配

- 扩展名规范化：`*.JPG, .png | mp4 jpg` → `jpg;png;mp4`（大小写统一、去点、去重）。
- `skip` 模式：命中列表跳过，未命中保留。
- `copy/move/rename` 模式：未命中跳过，命中保留。
- 空列表不执行过滤。
- `*` 通配全部：`skip` 模式全部跳过，`rename` 模式全部保留。
- 中文别名：跳过/复制/移动/重命名分别规范化为 skip/copy/move/rename。
- 动作匹配：
  - `rename` + 同目录 → 重命名。
  - `rename` + 目标目录变化 → 复制。
  - `copy` → 复制；`move` → 移动。
  - 白名单模式未命中 → 跳过；跳过模式命中 → 跳过。
  - 跳过模式未命中 + 同目录 → 重命名；目标目录变化 → 复制。

## 5. 风险与限制

| 风险 | 影响 | 缓解 |
|---|---|---|
| Quicker 实机 WPF/C# 5 环境差异 | XAML 控件或 `System.Windows.Forms` 引用可能需调整 | 已按官方文档与 C# 5 编写；提供实机测试清单 |
| DataGrid 绑定到词典索引器 | 行刷新/ToolTip 显示可能因 Quicker 修改版 WPF 而异 | 使用 `Items.Refresh()`；实机优先验证 |
| 静态状态与多窗口 | 同时打开多个窗口可能互相覆盖状态 | 按单实例使用；关闭事件校验窗口引用 |
| EXIF 依赖系统编解码器 | 部分 HEIC/WebP/RAW 读不到日期 | 回退到修改/创建日期；提示来源 |
| 哈希耗时 | 大文件/BLAKE3 计算较慢 | 后台线程、进度、缓存、按需计算 |
| 跨平台长度限制 | 部分系统可接受的长路径被提前拒绝 | 阈值可调整；错误提示明确 |
| 实时刷新关闭 | 用户可能忘记点击预览 | 状态提示、生成输出禁用、预览按钮启用 |
| 多预设嵌套词典 | Quicker“保存为状态”会把嵌套词典读回为JSON文本 | 启动时 `TryParseJson` 还原；旧版扁平预设兼容 |
| 执行文件操作 | 复制/移动/重命名不可完全回滚，磁盘/权限/占用可能导致部分失败 | 逐项报错并继续；目标不覆盖；跨卷移动先复制校验后删除 |
| 执行后校验耗时 | 大文件/BLAKE3需重读目标文件，总耗时增加 | 可关闭执行后校验；进度与速度可见 |
| 执行中关闭窗口 | 长文件操作可能延迟关闭 | 确认后停止领取新任务，等待已开始项目完成 |
| 原生复制兼容性 | 极少数虚拟文件系统/加密文件不支持 `CopyFileEx` | 仅对不支持类错误回退托管流；其他错误报错并重试 |
| 网络/USB吞吐 | SMB、VPN、USB供电/主控差异导致速度波动 | 按类型选缓冲、网络重试、可移动盘落盘刷新；需实机调优 |
| SSD/HDD介质区分 | 标准 `DriveInfo` 无介质类型，无法自动区分 | 固定盘统一策略，大文件4 MiB；必要时引入WMI（Q-14） |
| 进程崩溃残留临时文件 | 复制中进程崩溃可能留下 `.qk-*.tmp` | 临时文件不带目标文件名，不影响目标；后续可增加启动清理 |

## 6. 结论

- 核心日期、校验码（含 BLAKE3 官方向量）、模板、路径、跨平台校验、5槽递补、过滤器4种模式与动作匹配、文件传输性能/RAS、预设0.05与输出配对逻辑、预设状态JSON文本解析已通过 213 项自动化测试。
- 辅助 C# 代码已按 C# 5 与 .NET Framework 4.8 参考程序集完成类型检查。
- XAML 已通过 XML 结构、命名空间、控件命名与事件声明检查。
- release 两套方案 XAML 均通过 XML 解析；方案1无执行控件、方案2无生成输出按钮，DeliveryMode 分别为1/2。
- Windows原生复制、跨盘/跨卷、网络/UNC、USB/外置盘、SSD/HDD真实吞吐与掉盘/断网场景需在 Windows/Quicker 实机按第4章清单验收。
