### 2.2 BLAKE3 官方向量

使用 BLAKE3 官方仓库 `test_vectors/test_vectors.json` 的 `hash` 输出，输入为 `0,1,2,...,250,0,1,...` 循环字节串。测试长度：

```text
0, 1, 2, 3, 4, 5, 6, 7, 8, 63, 64, 65,
1023, 1024, 1025, 2048, 2049, 3072,
4096, 5120, 8192, 16384, 31744, 102400
```

全部与官方结果一致，覆盖了 64 字节块边界、1024 字节 chunk 边界、chunk 树合并以及大于 81920 字节读取缓冲区的输入。

### 2.5 示例1验证

输入路径：`C:\A\B\C\D.TXT`

模板：

```text
【根路径】/【日期yyyy】.【日期mm】/aaa/bbb/【源文件名】-【校验码】.【扩展名】
```

参数：根路径=当前文件夹，日期=2020-06，校验码=`[CRC32_4-7f7f]`。

实际输出：

```text
C:\A\B\C\2020.06\aaa\bbb\D-[CRC32_4-7f7f].TXT
```

与修订后的需求示例一致（路径分隔符按 Windows 规范使用反斜杠）。

### 2.6 预设往返

测试配置包含：

```text
rootMode=custom, rootPath=D:\Out, startYear=2010, dateSource=exif,
checksumAlgorithm=SHA-256, checksumDigits=16,
checksumPrefix=P, checksumSuffix=S,
template=【根路径】/X-【校验码】.【扩展名】
```

`BuildPresetDictionary` → `ApplyPresetDictionary` 后，全部键值一致；另验证：

- 部分预设只更新存在的键。
- CRC32 位数 99 被规范化为 8。
- 中文“修改日期”“其他文件夹”、`sha256` 别名被正确识别。

## 4. 未执行的人工测试清单

以下项目必须在 Windows + Quicker 实机完成：

1. 打开动作，确认 XAML 正常渲染，无 XAML 解析错误。
2. 输入包含文件与文件夹的列表，确认文件夹被跳过，状态栏计数正确。
3. 准备含 `2020-02-02`、`20200202`、无日期、EXIF 日期的文件，切换日期来源检查生效日期。
4. 修改最早起始年份，确认【文件名中的日期】即时重算。
5. 悬浮表格行，确认 ToolTip 显示四类日期、大小、校验码、目标路径与状态。
6. 切换根路径为“其他文件夹”，确认弹出文件夹选择器；取消时行为符合预期。
7. 编辑模板与点击七个胶囊，确认胶囊插入到光标位置，目标路径实时刷新。
8. 切换 CRC32/BLAKE3/MD5/SHA-256 与不同位数，确认格式预览与目标路径中的校验码一致。
9. 点击保存预设，关闭并重新打开动作，点击载入预设，确认全部配置恢复。
10. 点击生成输出，确认两个列表顺序、内容与预设正确；取消时列表为空。
11. 构造非法模板、重复目标、已存在目标，确认行标红且生成输出时弹窗确认。
12. 大批量文件（如 500+）检查扫描进度、哈希进度与 UI 响应。

## 5. 风险与限制

| 风险 | 影响 | 缓解 |
|---|---|---|
| Quicker 实机 WPF/C# 5 环境差异 | XAML 控件或 `System.Windows.Forms` 引用可能需调整 | 已按官方文档与 C# 5 编写；提供实机测试清单 |
| DataGrid 绑定到词典索引器 | 行刷新/ToolTip 显示可能因 Quicker 修改版 WPF 而异 | 使用 `Items.Refresh()`；实机优先验证 |
| 静态状态与多窗口 | 同时打开多个窗口可能互相覆盖状态 | 按单实例使用；关闭事件校验窗口引用 |
| EXIF 依赖系统编解码器 | 部分 HEIC/WebP/RAW 读不到日期 | 回退到修改/创建日期；提示来源 |
| 哈希耗时 | 大文件/BLAKE3 计算较慢 | 后台线程、进度、缓存、按需计算 |
| 无扩展名/保留名/长路径 | 目标路径可能被系统拒绝 | 路径校验标记错误；后续版本增强 |

## 6. 结论

- 核心日期、校验码（含 BLAKE3 官方向量）、模板、路径与预设逻辑已通过 89 项自动化测试。
- 辅助 C# 代码已按 C# 5 与 .NET Framework 4.8 参考程序集完成类型检查。
- XAML 已通过 XML 结构、命名空间、控件命名与事件声明检查。
- 当前版本可以进入 Windows/Quicker 实机联调；界面交互与 DataGrid 绑定需按第4章清单验收。
