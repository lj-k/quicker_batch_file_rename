## 2. 项目概述

开发一个运行于 Quicker 的批量重命名器，使用 Quicker 的【自定义窗口】动作承载界面。动作需要读取输入文件路径，获取文件属性（重点为多种日期属性），按照用户配置的规则组合出新的目标路径和文件名，并在窗口中实时预览。

该窗口仅用于配置与预览，不执行最终的重命名、移动或复制操作。窗口最终输出两个列表和一个预设词典，供后续动作步骤使用。

## 3. 输入与输出

### 3.1 输入

| 输入项 | 类型 | 说明 |
|---|---|---|
| 【输入文件路径】 | 列表 | 待处理的文件路径集合。处理时先判断是否为文件，文件夹跳过 |
| 【最早起始年份】 | 配置参数 | 默认 2000 年，用于限定【文件名中的日期】可接受的年份范围 |
| 【批量重命名器预设】 | 词典 | 用于载入历史配置；保存时更新为当前全部配置参数 |

### 3.2 输出

| 输出项 | 类型 | 说明 |
|---|---|---|
| 【原路径和文件名】 | 列表 | 预览中参与处理的源文件路径 |
| 【目标路径和文件名】 | 列表 | 按当前配置与模板组合得到的目标路径和文件名 |
| 【批量重命名器预设】 | 词典 | 保存全部配置参数，采用 Quicker 词典格式 |

输出约束：

- 展示界面仅供预览，不做最终处理，不得在预览阶段修改文件系统。
- 输出列表与预设的具体内容、顺序及异常行处理规则见第10章待确认事项。

## 4. 平台与技术约束

依据 Quicker 官方文档，【自定义窗口】具有以下约束 [1][2]：

- 窗口通过 XAML（WPF）定义，支持简单的数据绑定与事件处理。
- XAML 中需要去掉 `x:Class` 属性，不支持在 XAML 中直接指定事件处理方法。
- 需要注册命名空间 `xmlns:qk="https://getquicker.net"`。
- 通过【数据映射】把动作变量引入窗口数据；窗口结束时，窗口数据会写回关联的动作变量。
- 可通过【辅助C#代码】提供 `OnWindowCreated`、`OnWindowLoaded`、`OnButtonClicked` 等回调，用于初始化、事件处理和数据计算。
- 该功能在官方文档中标注为预览状态，可能存在缺陷或发生改动，开发和测试时需考虑版本兼容性。

## 5. 功能需求

### 5.1 文件筛选

1. 遍历【输入文件路径】列表中的每一项。
2. 先判断该项是否为文件。
3. 文件夹直接跳过，不进入预览表格，也不进入最终输出列表。

### 5.2 文件日期属性获取

需要获取并可选择以下四类日期，原文给出的顺序为：

| 顺序 | 日期类型 | 获取规则 |
|---|---|---|
| 1 | 【文件名中的日期】 | 在文件名中匹配日期；按顺序获取任意一个即停止 |
| 2 | 【exif拍摄日期】 | 读取文件的 EXIF 拍摄日期 |
| 3 | 【修改日期】 | 读取文件修改日期 |
| 4 | 【创建日期】 | 读取文件创建日期 |

【文件名中的日期】的匹配规则：

- 匹配格式1（先验）：`yyyy-mm-dd`，例如 `2020-02-02`。
- 匹配格式2（先验）：`yyyymmdd`，例如 `20200202`。
- 先验条件：匹配位置必须是字符串起始，或前一个字符不是数字。
- 年份 `yyyy` 的允许范围：【最早起始年份】至当前年份（含边界）。
- 在【文件名中的日期】内部，匹配到任意一个符合规则的日期后即停止，不再继续查找其他日期。
- 两种格式的尝试顺序、匹配后边界及同一格式多次出现时的取舍，按原文"按顺序获取任意一个即停止"执行；细节待确认（见第10章）。

### 5.3 主界面与实时预览

窗口包含两个部分：

1. **配置框**：用于配置目标路径名和文件名的生成规则。
2. **表格**：用于预览源路径与目标路径。

表格要求：

| 列 | 内容 |
|---|---|
| 第1列 | 源路径名 |
| 第2列 | 目标路径名/文件名 |

交互要求：

- 鼠标悬浮在表格行上时，显示该文件的各种属性信息。
- 任意配置变更后，目标路径名/文件名需要实时刷新。
- 表格仅用于预览，不执行最终处理。

### 5.4 配置项

#### 配置1：根路径

- 可选择【当前文件夹】或【其他文件夹】。
- 当用户选择【其他文件夹】时，跳出文件夹选择器。
- "当前文件夹"的目录口径待确认（见第10章）。

#### 配置2：最早起始年份

- 默认值为 2000。
- 当该配置变更时，重新获取【文件名中的日期】。

#### 配置3：日期

从以下四项中四选一：

- 【文件名中的日期】
- 【exif拍摄日期】
- 【修改日期】
- 【创建日期】

选中的日期来源用于模板中的【日期yyyy】、【日期mm】、【日期dd】。

#### 配置4：校验码

包含以下子配置：

| 子配置 | 取值/说明 |
|---|---|
| 【校验算法】 | CRC32、BLAKE3、MD5、SHA-256 |
| 【校验位数】 | 1 至该算法的最高位数；位数为16进制位数 |
| 【校验码前缀】 | 用户可配置 |
| 【校验码后缀】 | 用户可配置 |

校验码显示格式：

- 当校验位数等于该算法的默认最高位数时：`[CRC32-7f7f7f7f]`。
- 当校验位数小于默认最高位数时：`[CRC32_4-7f7f]`，其中 `4` 表示16进制位数，`7f7f` 为截取后的校验码。
- 默认最高位数按算法标准输出长度换算（待确认 BLAKE3 的输出长度口径，见第10章）：
  - CRC32：8 位16进制
  - BLAKE3：64 位16进制（32字节默认输出）
  - MD5：32 位16进制
  - SHA-256：64 位16进制

【校验码前缀】、【校验码后缀】与算法标识、连字符、方括号的组合方式，原文未给出明确示例，见第10章待确认事项。

#### 配置5：目标路径和文件名编辑器

- 编辑器中可点击胶囊（模板变量按钮），在当前光标位置插入胶囊。
- 需要支持以下胶囊：

| 胶囊 | 含义 |
|---|---|
| 【日期yyyy】 | 四位年份 |
| 【日期mm】 | 两位月份 |
| 【日期dd】 | 两位日期 |
| 【根路径】 | 根据【根路径】配置得到的根目录 |
| 【源文件名】 | 源文件名，不带扩展名 |
| 【扩展名】 | 文件扩展名 |
| 【校验码】 | 按校验码配置生成的校验码文本 |

- 胶囊插入位置必须为目标路径编辑框的当前光标位置。
- 日期胶囊的值来自【配置3】所选日期来源。

### 5.5 示例

原文示例1：

```text
输入路径为：C://A/B/C/D.TXT
目标路径和文件名编辑器内容为：【根路径】/【日期yyyy】.【日期mm】/aaa/bbb/【源文件名】-【校验码】.【扩展名】
配置1【根路径】=当前文件夹，【校验码】=（[CRC32_4-7f7f]）
重命名后的内容为：C://A/B/C/aaa/bbb/D-[CRC32_4-7f7f].TXT
```

说明：原文示例中，模板包含 `【日期yyyy】.【日期mm】/`，但示例结果未包含该日期层级（`2020.02/`）。该不一致需确认，见第10章。

### 5.6 预设载入与保存

- 配置框中提供【载入】和【保存】两个按钮。
- 【载入】：载入【批量重命名器预设】中的配置。
- 【保存】：保存当前全部配置参数。
- 预设输出为 Quicker 的词典格式，对应词典【批量重命名器预设】。
- 需保存的配置参数至少包括：
  - 根路径模式与根路径值
  - 最早起始年份
  - 日期来源
  - 校验算法
  - 校验位数
  - 校验码前缀
  - 校验码后缀
  - 目标路径和文件名编辑器中的模板内容
- 预设的存储位置、命名方式及词典键名结构待确认（见第10章）。

## 6. 交互规则汇总

| 编号 | 交互 | 规则 |
|---|---|---|
| I-01 | 配置变更 | 目标路径名/文件名实时刷新 |
| I-02 | 表格行悬浮 | 显示该文件的各种属性信息 |
| I-03 | 选择【其他文件夹】 | 跳出文件夹选择器 |
| I-04 | 修改【最早起始年份】 | 重新获取【文件名中的日期】 |
| I-05 | 点击胶囊 | 在目标路径编辑框当前光标位置插入对应胶囊 |
| I-06 | 点击【载入】/【保存】 | 载入或保存全部配置参数到预设词典 |
| I-07 | 预览阶段 | 不执行最终处理，不修改文件 |

## 7. 验收标准

以下条目用于验收，待确认事项确认后需补充对应细则：

1. 输入列表中的文件夹被跳过，不进入预览表格及输出列表。
2. 能从文件名中识别 `yyyy-mm-dd` 与 `yyyymmdd` 两种日期格式，并遵守先验条件及年份范围。
3. 【最早起始年份】变更后，【文件名中的日期】重新计算。
4. 四类日期均可获取，并可在【配置3】中选择。
5. 表格严格展示两列：源路径名、目标路径名/文件名。
6. 鼠标悬浮表格行时，可查看该文件的各种属性信息。
7. 任意配置变更后，目标路径名/文件名实时刷新。
8. 【根路径】支持当前文件夹与其他文件夹；选择其他文件夹时出现文件夹选择器。
9. 校验码支持 CRC32、BLAKE3、MD5、SHA-256，位数范围为 1 至算法最高位数，并按规则显示 `[CRC32-7f7f7f7f]` 或 `[CRC32_4-7f7f]`。
10. 编辑器支持七种胶囊，并能在光标位置插入。
11. 【载入】/【保存】可完整往返全部配置参数。
12. 窗口输出两个列表和一个预设词典，预览过程不修改任何文件。
13. 示例1的模板与结果一致性按确认后的规则通过测试。

## 8. 非功能要求

| 类别 | 要求 |
|---|---|
| 平台兼容 | 必须作为 Quicker【自定义窗口】动作运行，符合第4章约束 |
| 数据安全 | 预览阶段不得执行重命名、移动、复制、删除等文件系统写操作 |
| 配置完整性 | 预设需保存第5.6节列出的全部配置参数 |
| 实时性 | 配置变更后目标路径预览需实时刷新（具体时限未定义，见第10章） |
| 可维护性 | 模板、预设、校验码规则应保持结构清晰，便于后续扩展算法与胶囊 |

## 9. 需求边界

- 本需求只定义配置、预览和输出，不定义实际执行重命名的动作步骤。
- 本需求不定义目标目录的自动创建行为。
- 本需求不定义文件冲突时的自动改名、覆盖或跳过策略。
- 本需求不定义多套命名预设的管理界面。

以上未定义内容如需实现，应作为新增需求另行确认。
