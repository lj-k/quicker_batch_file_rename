## 2. 项目概述

开发一个运行于 Quicker 的批量重命名器，使用 Quicker 的【自定义窗口】动作承载界面。动作需要读取输入文件路径，获取文件属性（重点为多种日期属性），按照用户配置的规则组合出新的目标路径和文件名，并在窗口中实时预览。

该窗口用于配置、预览与执行：预览不修改文件；点击【执行】后按展示列表的动作完成复制、移动或重命名。窗口最终输出两个路径列表、一个动作列表和一个预设词典，供后续动作步骤使用。

## 3. 输入与输出

### 3.1 输入

| 输入项 | 类型 | 说明 |
|---|---|---|
| 【输入文件路径】 | 列表 | 待处理的文件路径集合。处理时先判断是否为文件，文件夹跳过 |
| 【最早起始年份】 | 配置参数 | 默认 2000 年，用于限定【文件名中的日期】可接受的年份范围 |
| 【批量重命名器预设】 | 词典 | 用于载入/保存多套命名配置 |
| 【扩展名预设】 | 词典 | 用于保存和载入过滤器扩展名列表；载入可选覆盖或追加 |

### 3.2 输出

| 输出项 | 类型 | 方案1：仅重命名不执行 | 方案2：执行不输出列表 |
|---|---|---|---|
| 【原路径和文件名】 | 列表 | 输出，仅非跳过且目标有效项 | 不生成、不输出 |
| 【目标路径和文件名】 | 列表 | 输出，仅非跳过且目标有效项 | 不生成、不输出 |
| 【批量重命名器预设】 | 词典 | 输入/输出 | 输入/输出 |
| 【扩展名预设】 | 词典 | 输入/输出 | 输入/输出 |

输出约束：

- 方案1只输出两个路径列表，不再输出动作列表；两个列表必须序号一致、长度相等，第 n 项来自同一源文件。
- 方案1的两个列表只包含非跳过项；过滤跳过、日期跳过、动作跳过均不输出。
- 方案2不初始化、不写入任何路径列表或动作列表变量。
- 展示界面用于预览与执行：预览、配置变化阶段不得修改文件系统；只有方案2点击【执行】后才按列表动作修改文件。
- 两个方案都提供【完成】按钮；点击后关闭窗口并继续执行 Quicker 后续动作步骤。

## 4. 平台与技术约束

依据 Quicker 官方文档，【自定义窗口】具有以下约束 [1][2]：

- 窗口通过 XAML（WPF）定义，支持简单的数据绑定与事件处理。
- XAML 中需要去掉 `x:Class` 属性，不支持在 XAML 中直接指定事件处理方法。
- 需要注册命名空间 `xmlns:qk="https://getquicker.net"`。
- 通过【数据映射】把动作变量引入窗口数据；窗口结束时，窗口数据会写回关联的动作变量。
- 可通过【辅助C#代码】提供 `OnWindowCreated`、`OnWindowLoaded`、`OnButtonClicked` 等回调，用于初始化、事件处理和数据计算。
- 该功能在官方文档中标注为预览状态，可能存在缺陷或发生改动，开发和测试时需考虑版本兼容性。

## 5. 功能需求

### 5.1 文件筛选

1. 遍历【输入文件路径】列表中的每一项。
2. 先判断该项是否为文件。
3. 文件夹直接跳过，不进入预览表格，也不进入最终输出列表。

### 5.2 文件日期属性获取

需要获取并可选择以下四类日期，原文给出的顺序为：

| 顺序 | 日期类型 | 获取规则 |
|---|---|---|
| 1 | 【文件名中的日期】 | 在文件名中匹配日期；按顺序获取任意一个即停止 |
| 2 | 【exif拍摄日期】 | 读取文件的 EXIF 拍摄日期 |
| 3 | 【修改日期】 | 读取文件修改日期 |
| 4 | 【创建日期】 | 读取文件创建日期 |

【文件名中的日期】的匹配规则：

- 匹配格式1（先验）：`yyyy-mm-dd`，例如 `2020-02-02`。
- 匹配格式2（先验）：`yyyymmdd`，例如 `20200202`。
- 先验条件：匹配位置必须是字符串起始，或前一个字符不是数字，保障不会从更长数字串的中间开始匹配。
- 不要求匹配后边界：日期后面可能是时间、文件名或连接符，不能据此拒绝。
- 年份 `yyyy` 的允许范围：【最早起始年份】至当前年份（含边界）。
- 在【文件名中的日期】内部，匹配到任意一个符合规则的日期后即停止，不再继续查找其他日期。
- 两种格式的尝试顺序、同一格式多次出现时的取舍，按原文“按顺序获取任意一个即停止”执行；仍作为待确认项记录（见第10章）。

### 5.3 主界面与实时预览

窗口包含两个部分：

1. **配置框**：用于配置目标路径名和文件名的生成规则。
2. **表格**：用于预览源路径与目标路径。

表格要求：

| 列 | 内容 |
|---|---|
| 第1列 | 源路径名 |
| 第2列 | 目标路径名/文件名 |

交互要求：

- 鼠标悬浮在表格行上时，显示该文件的各种属性信息。
- 提供【实时刷新】开关：
  - 开启时，配置变更后目标路径名/文件名实时刷新。
  - 关闭时，配置变更不立即刷新目标路径；用户点击【预览】按钮手动刷新。
- 表格仅用于预览，不执行最终处理。

### 5.4 配置项

#### 配置0：过滤器

- 位于根路径卡片上方。
- 功能与 `https://github.com/lj-k/APP_FileSettle` 保持同步；当前可访问版本/仓库内容见第12章说明。
- 决策模式支持四种：
  - 【跳过】：命中扩展名列表的文件跳过；未命中的文件按模板执行（同目录为重命名，跨目录为复制）。
  - 【复制】：仅命中扩展名列表的文件复制到目标路径；未命中文件跳过。
  - 【移动】：仅命中扩展名列表的文件移动到目标路径；未命中文件跳过。
  - 【重命名】：仅命中扩展名列表的文件重命名；未命中文件跳过。
- 扩展名列表为空表示不过滤，所有文件都参与决策。
- 决策为【重命名】时，目标路径和文件名编辑器的默认内容为：
  `【根路径】/【源文件名】-【校验码】.【扩展名】`
  - 仅当模板仍是默认模板时随模式切换自动替换，避免覆盖用户手工修改。
- 动作自动匹配规则：
  - 决策为【重命名】且目标目录与源目录相同 → 动作【重命名】。
  - 决策为【重命名】但模板加入中间文件夹，导致目标目录变化 → 动作【复制】。
  - 决策为【复制】→ 动作【复制】；决策为【移动】→ 动作【移动】。
  - 决策为【跳过】且未命中排除列表时，按目标目录是否变化得到【重命名】或【复制】。
- 扩展名列表支持分隔符、通配符和空列表。
- 提供动作词典变量【扩展名预设】，用于保存和载入扩展名列表。
- 载入扩展名预设时可选：
  - 覆盖现有扩展名列表。
  - 追加到现有扩展名列表（append）。
- 保存预设和扩展名预设时，应尽量实时更新对应的 Quicker 动作变量；若窗口环境不支持实时写变量，则窗口关闭时通过数据映射写回。

#### 配置1：根路径

- 默认【当前文件夹】。
- 可选择【当前文件夹】或【其他文件夹】。
- 当用户选择【其他文件夹】时，跳出文件夹选择器。
- 【当前文件夹】明确指每个源文件所在目录。

#### 配置2：最早起始年份

- 默认值为 2000。
- 当该配置变更时，重新获取【文件名中的日期】。

#### 配置3：日期

**配置3.1：日期来源**

从以下四项中四选一，默认【文件名中的日期】：

- 【文件名中的日期】
- 【exif拍摄日期】
- 【修改日期】
- 【创建日期】

选中的日期来源用于模板中的【日期yyyy】、【日期mm】、【日期dd】。

**配置3.2：缺失递补**

- 取消“是否启用缺失递补”开关和“递补关闭时缺失值”设置。
- 递补1~5在同一行展示。
- 每个递补下拉均可选择：
  - 【文件名中的日期】
  - 【exif拍摄日期】
  - 【修改日期】
  - 【创建日期】
  - 【空值】
  - 【自定义】
  - 【跳过】
- 递补5用于最终兜底，默认【空值】。
- 【空值】：三个日期胶囊【日期yyyy】【日期mm】【日期dd】都输出空值，并停止继续递补。
- 【自定义】：使用统一的自定义值替换三个日期胶囊，并停止继续递补。
- 【跳过】：命中该项时不再处理该文件，也不输出该文件。
- 主日期来源缺失后，按递补1→5顺序处理；日期来源可用则采用，遇到空值/自定义/跳过则立即结束。

#### 配置4：校验码

包含以下子配置：

| 子配置 | 取值/说明 |
|---|---|
| 【校验算法】 | CRC32、BLAKE3、MD5、SHA-256 |
| 【校验位数】 | 1 至该算法的最高位数；位数为16进制位数 |
| 【校验码前缀】 | 用户可配置 |
| 【校验码后缀】 | 用户可配置 |

校验码显示格式：

- 【校验码前缀】默认为 `[`，【校验码后缀】默认为 `]`。
- 输出结构为：`前缀 + 算法标识[_位数] + "-" + 校验码 + 后缀`。
- 当校验位数等于该算法的默认最高位数时，算法标识不显示位数：`[CRC32-7f7f7f7f]`。
- 当校验位数小于默认最高位数时，算法标识追加 `_位数`：`[CRC32_4-7f7f]`，其中 `4` 表示16进制位数，`7f7f` 为截取后的校验码。
- 校验码截取取高位；默认完整长度。
- 默认最高位数按算法标准输出长度换算：
  - CRC32：8 位16进制
  - BLAKE3：64 位16进制（32字节默认输出）
  - MD5：32 位16进制
  - SHA-256：64 位16进制

校验码例1：

```text
【校验算法】= CRC32
【校验位数】= 8
【校验码前缀】= [
【校验码后缀】= ]
输出 = [CRC32-7f7f7f7f]
```

#### 配置5：目标路径和文件名编辑器

- 编辑器中可点击胶囊（模板变量按钮），在当前光标位置插入胶囊。
- 需要支持以下胶囊：

| 胶囊 | 含义 |
|---|---|
| 【日期yyyy】 | 四位年份 |
| 【日期mm】 | 两位月份 |
| 【日期dd】 | 两位日期 |
| 【根路径】 | 根据【根路径】配置得到的根目录 |
| 【源文件名】 | 源文件名，不带扩展名 |
| 【扩展名】 | 文件扩展名 |
| 【校验码】 | 按校验码配置生成的校验码文本 |

- 胶囊插入位置必须为目标路径编辑框的当前光标位置。
- 日期胶囊的值来自【配置3】确定的日期；日期缺失时按【配置3.2】处理。
- 默认模板为：

```text
【根路径】/【日期yyyy】.【日期mm】/aaa/bbb/【源文件名】-【校验码】.【扩展名】
```

- 输出路径分隔符统一为 Windows 反斜杠 `\`。

### 5.5 示例

原文示例1：

```text
输入路径为：C://A/B/C/D.TXT
目标路径和文件名编辑器内容（默认）：【根路径】/【日期yyyy】.【日期mm】/aaa/bbb/【源文件名】-【校验码】.【扩展名】
配置1【根路径】=当前文件夹，【校验码】=（[CRC32_4-7f7f]）
重命名后的内容为：C://A/B/C/2020.06/aaa/bbb/D-[CRC32_4-7f7f].TXT
```

示例结果中的 `2020.06` 对应模板里的 `【日期yyyy】.【日期mm】/` 层级；输出实际使用 Windows 反斜杠。

### 5.6 预设载入与保存

- 窗口最上方提供【载入预设】和【保存预设】两个按钮。
- 【载入预设】：点击后展示预设下拉框；选择某个预设后载入其全部配置。
- 【保存预设】：点击后要求输入预设名称并保存当前全部配置参数。
- 若输入的名称与现有预设冲突：
  - 提示是否覆盖。
  - 显示发生变更的配置项目（旧值 → 新值）。
  - 用户确认后才覆盖。
- 预设输出为 Quicker 的词典格式，对应词典【批量重命名器预设】；词典支持多套命名预设。
- 需保存的配置参数至少包括：
  - 过滤器扩展名列表、决策模式（跳过/复制/移动/重命名）
  - 根路径模式与根路径值
  - 最早起始年份
  - 日期来源
  - 递补1~5（日期来源/空值/自定义/跳过）与统一自定义文本
  - 实时刷新开关
  - 执行并行数量（1~8）
  - 执行后校验开关
  - 校验算法
  - 校验位数
  - 校验码前缀
  - 校验码后缀
  - 目标路径和文件名编辑器中的模板内容
- 预设词典格式需随可配置项增加而更新。
- 旧版单预设词典应能识别并作为“默认”预设载入。
- 生成输出时若尚未保存任何预设，应至少输出当前配置作为“默认”预设。
- 保存预设时应尽量实时更新 Quicker 动作变量【批量重命名器预设】；若环境不支持实时写入，则在窗口关闭时通过数据映射写回。
- 提供独立动作词典变量【扩展名预设】，用于保存和载入扩展名列表；载入时可选覆盖现有或追加（append）现有。
- 预设的存储位置、命名方式及词典键名结构见第10章待确认事项。

### 5.7 路径校验与错误提示

目标路径和文件名编辑器生成的路径必须通过跨平台校验：

- 非法字符取 Linux、Windows、macOS、Android 的并集，至少包括：
  - Windows：`< > : " / \ | ? *` 及 ASCII 控制字符。
  - macOS：`:`、`/`。
  - Linux：`/`、NUL。
  - Android：`/`、NUL。
- 其他非法路径问题：
  - 空路径、空路径段。
  - `.`、`..` 目录段。
  - 路径段以空格或点结尾。
  - Windows 保留设备名（CON、PRN、AUX、NUL、COM1–COM9、LPT1–LPT9 等）。
  - 路径段超长、总路径超长。
  - 非绝对路径、缺少文件名、UNC 路径缺少服务器/共享/文件名。
- 发现非法路径时：
  - 在窗口上方以红字显示错误提示。
  - 使用红底高亮表格中的异常行。
  - 校验结果需能指出具体的非法字符或非法路径问题。

### 5.8 界面布局与悬浮说明

- 过滤器卡片位于根路径上方；其后为根路径、日期、校验码、模板四张卡片，纵向排列。
- 卡片标题放在卡片左侧竖排区域，不占用卡片顶部纵向空间。
- 卡片说明不占用正文空间，改为鼠标悬浮在卡片标题上时显示。
- 每个配置卡片对应的输出胶囊放在同一行的右侧：
  - 根路径卡片右侧：【根路径】。
  - 日期卡片右侧：【日期yyyy】、【日期mm】、【日期dd】。
  - 校验码卡片右侧：【校验码】。
- 模板卡片位于配置卡片下方，模板输入框在左，其余胶囊（【源文件名】、【扩展名】）在右。
- 所有胶囊在右侧列成一列，便于对齐和插入。
- 【载入预设】【保存预设】按钮位于窗口最上方。
- 展示列表为三列：动作、源路径名、目标路径名/文件名。
- 展示列表下方为执行配置框与【执行】按钮。
- 所有配置项、胶囊、预设按钮、预览/输出/执行按钮均应提供悬浮提示，说明选项含义、输出结果和可能的后果，包括非法路径、重名、哈希耗时、缺失日期、过滤跳过、覆盖与停止执行等。

### 5.9 执行配置与执行

- 展示列表下方提供执行配置框，包含：
  - 【并行数量】下拉框：1~8，默认2。
  - 【执行后校验】开关：默认开启。
  - 【执行】按钮。
  - 执行状态文本与进度条。
- 方案2显示执行配置；方案1隐藏执行配置与执行按钮。
- 展示列表行状态使用行背景色：成功浅绿、失败浅红、计算中浅黄、跳过浅灰；不通过修改字体颜色表达状态。
- 执行状态显示：
  - 执行总数。
  - 已完成数量（成功）。
  - 错误数量。
  - 传输速度（复制/跨卷移动的字节速度）。
  - 执行速度（完成项目数/秒）。
- 展示列表行状态：
  - 执行成功：底色标绿。
  - 执行出错：底色标红；鼠标悬浮显示错误原因。
  - 过滤跳过、日期跳过、动作跳过：灰底，不执行。
- 执行按钮规则：
  - 按展示列表的动作列执行；跳过行、异常行、校验码计算中的行不执行。
  - 执行前检查源文件是否存在。
  - 目标目录不存在时自动创建。
  - 目标文件已存在时不覆盖，该项报错。
  - 复制使用新增副本；移动在同一卷内直接移动，跨卷时先复制、校验、再删除源文件。
  - 重命名仅用于目标目录与源目录相同的场景；若模板加入中间文件夹，动作自动变为复制。
  - 执行期间禁用配置区与预设/预览/生成输出按钮；允许取消，取消后不再开始新项目，已开始的项目完成。
- 执行后校验：
  - 仅对复制和移动执行。
  - 重新计算目标文件校验码，与源文件校验码比较。
  - 若模板包含【校验码】，还检查目标文件名中是否包含按当前算法、位数、前后缀生成的校验码标记。
  - 校验算法与校验码配置一致。
- 方案1输出两个路径列表，只包含非跳过项，两者逐项配对；方案2不输出列表。

### 5.10 文件传输性能与RAS

#### 性能策略

- Windows 下优先使用系统原生 `CopyFileEx`（保留文件属性/时间戳、支持进度回调与取消）；不可用时回退到托管流式复制。
- 托管流式复制按目标驱动器类型与文件大小选择缓冲：
  - 网络/UNC：256 KiB。
  - 光驱：64 KiB。
  - U盘/外置可移动盘：默认1 MiB；文件≥512 MiB时2 MiB。
  - 固定盘/未知盘：默认1 MiB；文件≥1 GiB时4 MiB。
  - SSD与HDD无法通过标准 `DriveInfo` 可靠区分，统一按固定盘策略；大文件使用4 MiB。
- 固定盘且文件≥64 MiB时预分配目标文件长度，减少碎片与元数据扩展。
- 同卷移动/重命名直接 `File.Move`；跨卷移动采用“复制→校验→删除源文件”，复制阶段使用上述策略。
- 复制先写入同目录临时文件（`.qk-随机.tmp`），成功后再原子改名到目标，避免留下半成品目标。
- 复制完成后保留源文件的创建时间、修改时间与属性。
- 进度回调按已传输字节增量上报，执行状态中的传输速度可随复制实时更新。

#### RAS策略

- 目标已存在：拒绝覆盖并报错。
- 源文件不存在、路径无效、目标目录不可写：逐项报错，不中断其他项目。
- 复制/移动前检查目标磁盘可用空间（网络路径无法可靠获取时跳过检查）。
- 复制前后校验源文件长度与最后修改时间；复制期间源文件变化则删除临时文件并报错。
- 对共享冲突、锁定、网络超时/断开、设备未就绪等瞬态错误最多重试3次，退避200/400/800 ms；每次重试前清理临时文件，并在失败时回滚已上报的进度。
- 复制/移动后校验失败：复制动作删除目标文件；跨卷移动在删除源文件前校验，失败时删除目标并保留源文件。
- 可移动盘复制完成后执行落盘刷新；网络路径使用普通刷新以降低延迟。
- 执行中取消/关闭：不再领取新项目，已开始项目完成；执行线程全部退出后再关闭窗口。
- 错误信息转换为可读原因（占用、拒绝访问、空间不足、网络路径不可用、超时等）。

#### 场景覆盖

| 场景 | 策略 |
|---|---|
| 驱动器内复制 | 原生复制；临时文件+改名；进度/校验 |
| 驱动器内移动/重命名 | `File.Move`，失败重试 |
| 跨驱动器/跨盘复制 | 目标盘空间检查、原生/缓冲复制、临时文件 |
| 跨驱动器/跨盘移动 | 复制→校验→删除源；删除失败回滚目标 |
| 跨网络/远程/UNC | 256 KiB缓冲、网络错误重试、跳过不可靠空间检查 |
| U盘/外置盘 | 1~2 MiB缓冲、落盘刷新、校验 |
| SSD | 固定盘策略，大文件4 MiB缓冲 |
| HDD | 固定盘策略，预分配+顺序扫描提示，大文件4 MiB缓冲 |

## 7. 验收标准

以下条目用于验收，待确认事项确认后需补充对应细则：

1. 输入列表中的文件夹被跳过，不进入预览表格及输出列表。
2. 能从文件名中识别 `yyyy-mm-dd` 与 `yyyymmdd` 两种日期格式，遵守前边界、年份范围；不因后边界拒绝日期。
3. 【最早起始年份】变更后，【文件名中的日期】重新计算。
4. 四类日期均可获取，日期来源默认【文件名中的日期】，可四选一。
5. 日期递补1~5在同一行；每项可选四类日期、空值、自定义、跳过；递补5默认空值；空值下三个日期胶囊都为空；跳过文件不处理、不输出。
6. 【实时刷新】开启时配置变更即时刷新；关闭时点击【预览】按钮手动刷新。
7. 表格展示动作、源路径名、目标路径名/文件名三列；行悬浮显示属性。
8. 【根路径】默认当前文件夹（每个源文件所在目录），支持其他文件夹并弹出选择器。
9. 校验码支持 CRC32、BLAKE3、MD5、SHA-256；默认前后缀为 `[`、`]`，位数范围为 1 至算法最高位数，截取取高位。
10. 编辑器支持七种胶囊，并能在光标位置插入。
11. 卡片标题在左侧竖排区域，说明在标题悬浮显示；过滤器在根路径上方；根路径/日期/校验码相关胶囊在同行右侧；所有胶囊在右列；模板输入框在左、其余胶囊在右。
12. 默认模板包含 `aaa/bbb` 层级；重命名模式默认模板为 `【根路径】/【源文件名】-【校验码】.【扩展名】`；输出路径分隔符统一为 Windows 反斜杠。
13. 路径校验覆盖四个平台的非法字符并提示具体问题；异常时窗口上方红字提示，表格异常行红底高亮。
14. 预设按钮位于窗口顶部；载入显示预设下拉框；保存要求输入名称；同名冲突显示变更项目并询问覆盖；保存时尽量实时更新动作变量。
15. 所有配置项、胶囊、预设/预览/输出/执行按钮均有悬浮说明，覆盖含义、结果和后果。
16. 【载入】/【保存】可完整往返全部配置参数（含过滤器、执行并行与校验），旧版单预设可识别为“默认”。
17. 提供【扩展名预设】词典，支持扩展名列表保存；载入时可选择覆盖或追加。
18. 窗口输出两个路径列表、一个动作列表和一个预设词典；三者长度一致、序号对应同一文件；只有点击【执行】后才修改文件。
19. 示例1的结果包含 `2020.06` 日期层级，且与模板组合规则一致。
20. 过滤器决策模式支持跳过、复制、移动、重命名；重命名模式在模板加入中间文件夹时动作显示为复制。
21. 展示列表下方有执行配置框与执行按钮；并行数量1~8；执行后校验可开关。
22. 执行前检查源路径；目标目录不存在时自动创建；目标文件已存在时报错且不覆盖。
23. 复制/移动后可重新计算目标校验码，并与源校验码及文件名中的校验码标记核对。
24. 执行状态显示总数、完成、错误、传输速度、执行速度；成功行绿底、失败行红底并可悬浮查看原因。
25. 复制/移动按驱动器类型选择缓冲策略；Windows 优先使用系统原生复制，失败可回退托管流复制。
26. 跨卷移动按“复制→校验→删除源”执行；删除源失败时回滚目标。
27. 复制使用临时文件+改名，失败或取消后不留下半成品目标。
28. 瞬态错误最多重试3次，退避200/400/800 ms；错误原因可读。
29. 复制前检查目标空间与源文件稳定性；复制期间源文件变化应报错。
30. 复制完成后保留源文件时间戳与属性。
31. 展示列表成功/失败/计算中/跳过状态通过行背景色表达，不使用字体颜色。
32. 【取消】【生成输出】之后（方案2为【取消】之后）提供【完成】按钮；点击关闭窗口并继续 Quicker 后续步骤。
33. 方案1无执行配置/执行按钮，完成或生成输出时输出两个非跳过路径列表，不输出动作列表。
34. 方案2无【生成输出】按钮，不初始化/不写入任何路径列表或动作列表变量。
35. 两套交付方案共享源码、构建脚本与文档，版本同步更新。

## 9. 需求边界

- 本需求定义配置、预览、输出与执行；执行仅包含复制、移动、重命名。
- 本需求不定义删除、覆盖已有目标文件、自动改名等策略；目标已存在时当前按错误处理。
- 本需求不定义执行失败后的自动回滚（跨卷移动失败会尽量删除已复制目标，其他情况保留现状）。
- 多套命名预设的管理界面仅包含载入下拉与命名保存。

以上未定义内容如需实现，应作为新增需求另行确认。

## 13. 特别说明

特别说明（本次修订）：上一版示例1结果遗漏了 `2020.06/` 日期层级；正确结果为 `C://A/B/C/2020.06/aaa/bbb/D-[CRC32_4-7f7f].TXT`，应与模板中的 `【日期yyyy】.【日期mm】/` 保持一致。本版已修正示例与验收标准，并关闭原Q-01。

特别说明（修订2）：

- 文件名日期匹配：上一版要求日期后边界也必须为非数字；正确要求是只校验前边界，后边界不限制，因为日期后可能是时间、文件名或连接符。本版已修正。
- 校验码前后缀：上一版将方括号作为固定外层，并把用户前后缀放在方括号内部；正确做法是用户配置的【校验码前缀】/【校验码后缀】直接包裹“算法标识-校验码”，默认分别为 `[` 和 `]`。本版已修正。
- 默认模板：上一版默认模板不含 `aaa/bbb`；本版按新需求改为 `【根路径】/【日期yyyy】.【日期mm】/aaa/bbb/【源文件名】-【校验码】.【扩展名】`。
- 根路径：上一版未明确“当前文件夹”口径；本版明确为每个源文件所在目录，并作为默认模式。
- 本版新增：实时刷新开关与手动预览、日期缺失递补与缺失字符串、跨平台路径校验、顶部红字错误提示、输出列表长度与序号配对保证。

特别说明（界面交互重构）：

- 配置区改为纵向卡片：根路径、日期、校验码在左，相关胶囊在同一行右侧；模板输入框在左，其余胶囊在右；所有胶囊在右侧列成一列。
- 【载入预设】【保存预设】移到窗口最上方；载入改为下拉选择预设，保存改为输入名称并按需显示变更后覆盖。
- 新增递补5兜底值，默认空字符串；空字符串/空值下三个日期胶囊均为空。
- 全部配置项、胶囊与主要按钮增加悬浮提示，说明含义、结果和后果。

特别说明（过滤器与布局优化）：

- 配置文件区改为“过滤器、根路径、日期、校验码、模板”五张卡片；卡片标题放左侧，说明改为标题悬浮提示。
- 日期递补取消启用开关和缺失值设置，改为递补1~5同行，每项可选日期来源、空值、自定义、跳过；递补5默认空值。
- 过滤器按扩展名列表工作，决策模式为匹配时跳过或匹配时执行；新增【扩展名预设】词典，载入支持覆盖或追加。
- 保存预设/扩展名预设时尝试通过 `winContext.Context.SetVarValue` 实时更新 Quicker 动作变量；若当前版本未暴露该接口，则回退为窗口关闭时数据映射写回。
- APP_FileSettle 仓库本次无法访问，过滤器首版按扩展名规则实现；如该仓库还有关键词/正则/大小等规则，需要补充（见Q-11）。

特别说明（执行动作与执行配置）：

- 过滤器“决策模式”由上一版的“匹配时跳过/匹配时执行”扩展为“跳过/复制/移动/重命名”。当前实现口径：跳过=排除名单，其余三种=白名单；空扩展名列表表示不过滤。该口径作为Q-12记录，便于后续按实际使用调整。
- 重命名模式的默认模板改为 `【根路径】/【源文件名】-【校验码】.【扩展名】`；仅当模板仍为默认模板时随模式切换，避免覆盖用户手工模板。
- 展示列表新增“动作”列；重命名模式下若模板产生中间文件夹、目标目录与源目录不同，动作自动显示为“复制”。
- 输出在原有两个路径列表之外新增【执行动作】列表；三个列表只包含非跳过项并逐项配对。
- 新增执行配置框与【执行】按钮：并行1~8、执行后校验、执行状态（总数/完成/错误/传输速度/执行速度）、成功绿底/失败红底。
- 执行后校验仅作用于复制和移动：重算目标校验码并与源校验码比较；模板含【校验码】时还核对目标文件名中的校验码标记。
- 执行不覆盖已存在目标；目标目录不存在时自动创建；跨卷移动先复制、校验、再删除源文件。目标冲突策略作为Q-13记录。

特别说明（复制/移动性能与RAS专项）：

- 新增独立文件传输引擎：Windows优先 `CopyFileEx`，不可用时回退托管流式复制；按网络、光驱、可移动盘、固定盘与文件大小选择64 KiB~4 MiB缓冲。
- 复制先写同目录临时文件，成功后原子改名；失败/取消自动清理，避免留下半成品目标。
- 同卷移动/重命名直接 `File.Move`；跨卷移动为“复制→校验→删除源”，删除失败回滚目标。
- 增加瞬态错误重试（最多3次，200/400/800 ms）、目标空间检查、源文件稳定性检查、可读错误信息、时间戳/属性保留。
- 无法通过标准 `DriveInfo` 可靠区分SSD/HDD，当前统一按固定盘策略；作为Q-14记录。
- 上述策略已在Linux/Mono下对复制、移动、进度、临时文件清理、时间戳/属性、取消、错误信息等进行自动化测试；Windows原生复制、网络/UNC、USB/外置盘仍需实机性能验收。
