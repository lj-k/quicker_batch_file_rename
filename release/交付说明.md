# 批量重命名器 交付说明

> 版本：0.06

## 1. 交付方案

`release/` 下提供两套交付文件，两套方案共享同一份核心与界面代码，由 `tools/build_release.py` 生成。

| 方案 | 目录 | 特点 |
|---|---|---|
| 方案1：仅重命名不执行 | `release/方案1-仅重命名不执行/` | 无执行配置、无执行按钮；点击【完成】或【生成输出】输出两个非跳过路径列表 |
| 方案2：执行不输出列表 | `release/方案2-执行不输出列表/` | 无【生成输出】按钮；不生成/输出列表变量；使用【执行】完成复制/移动/重命名 |

两套方案都保留【完成】按钮，点击后关闭窗口并继续执行 Quicker 后续动作步骤。

## 2. 方案1：仅重命名不执行

- 窗口不显示执行配置框与【执行】按钮。
- 输出：列表【原路径和文件名】、列表【目标路径和文件名】，只包含非跳过且有有效目标路径的行。
- 不输出动作列表。
- 预设：【批量重命名器预设】、【扩展名预设】照常保存/写回。
- 数据映射：

```text
files:{输入文件路径}
startYear:{最早起始年份}
preset:{批量重命名器预设}
extensionPresets:{扩展名预设}
origPaths:{原路径和文件名}
targetPaths:{目标路径和文件名}
```

- 适用：窗口只负责生成重命名计划，实际文件操作由后续 Quicker 步骤完成。

## 3. 方案2：执行不输出列表

- 窗口保留执行配置框与【执行】按钮。
- 不显示【生成输出】按钮；不初始化、不写入列表变量。
- 预设：【批量重命名器预设】、【扩展名预设】照常保存/写回。
- 数据映射：

```text
files:{输入文件路径}
startYear:{最早起始年份}
preset:{批量重命名器预设}
extensionPresets:{扩展名预设}
```

- 适用：窗口内直接完成复制/移动/重命名，后续步骤只使用预设或不再需要路径列表。

## 4. 共同行为

- 展示列表行状态使用**行背景色**表示：成功浅绿、失败浅红、计算中浅黄、跳过浅灰。
- 【完成】按钮位于【取消】之后；方案1位于【生成输出】之后。
- 预设结构版本保持 0.05，两套方案共用。
- 执行配置、执行后校验、传输性能与RAS策略见 [开发说明](../doc/开发说明.md) 与 [测试报告](../doc/测试报告.md)。

## 5. 重新生成

```bash
python3 tools/build_quicker_code.py
python3 tools/build_release.py
```

`build_release.py` 会：

1. 生成完整开发版 `dist/CustomWindow.xaml` 与 `dist/QuickerAux.cs`（DeliveryMode=0）。
2. 从共享 XAML 移除执行配置块，生成方案1。
3. 从共享 XAML 移除【生成输出】按钮，生成方案2。
4. 在方案1/2 的辅助代码中写入 `DeliveryMode=1/2`。

## 6. Quicker 动作组装

| 参数 | 值 |
|---|---|
| 操作类型 | 显示窗口并等待关闭 |
| 窗口XAML代码 | 对应方案目录的 `CustomWindow.xaml` |
| 辅助C#代码 | 对应方案目录的 `QuickerAux.cs` |
| 窗口标识 | `BatchRenamerWindow` |
| 窗口尺寸 | `1220,860` |
| 自动关闭时间 | `0` |

【完成】【生成输出】【执行】都会关闭窗口，从而继续执行 Quicker 后续步骤；如需放弃输出，使用【取消】。
